# Shandianshuo Android Releases

Public stable update channel for Shandianshuo Android.

The private Android source repository publishes validation builds separately. This public repository only hosts the stable manifest and APK assets that the Android client is allowed to offer from `关于闪电说 → 版本更新`.

- Stable manifest: `stable.json`
- Release assets: GitHub Releases in this repository

Only update `stable.json` when a build is approved for user-facing stable updates.
